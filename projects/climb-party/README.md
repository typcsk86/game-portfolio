# Climb Party

**Durum:** PC / Steam hazırlığında

![Climb Party kapak](media/cover.jpg)

2–6 kişilik çevrim içi asimetrik parti oyunu. Tırmanma ve stamina sistemi, Climber/Blocker rolleri, beş oyun modu, yetenek/silah dengesi ve EOS tabanlı lobi/eşleşme akışları geliştirdim.
